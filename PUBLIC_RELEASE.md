# What public release means for this project

**Status on October 26, 2026:** reviewed documentation and screenshots are stored in a **private** GitHub repository. The original personal tracker remains outside the repository. No workbook file or live workbook link is included.

## Plain-language definition

A **public release** makes a chosen version accessible to people outside the private project audience. The audience and access method matter: a public repository can be viewed by anyone, while an anyone-with-link workbook can be viewed by anyone who obtains its link even if it is not advertised on a website.

Saving or pushing files to a **private GitHub repository** is a backup with version history and access control. It does not itself make those files public. A **GitHub Release** is a named, usually versioned snapshot on the repository; creating one is separate from pushing a commit, and its accessibility follows the repository's visibility.
