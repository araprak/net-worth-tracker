# Public project showcase

**Publicly available on GitHub from October 26, 2026.** Anyone can view the repository without an invitation or a GitHub account.

[Open the project](https://github.com/araprak/net-worth-tracker) or [start the screenshot walkthrough](walkthrough.md).

## What everyone can see

- The project overview and professional case study.
- Five screenshots showing fictional financial data.
- A guided walkthrough of the dashboard, spending, fiscal reporting, investments and benchmark comparisons.
- The verification report, calculation conventions and known privacy limits.

This is the public release of the project showcase. A formal version number, tag or GitHub Release is not required to view or share it.

## What is outside this repository

The original personal tracker, earlier snapshots, raw audit evidence, credentials and internal working files are excluded. The repository does not include a downloadable workbook or a live workbook link. The portfolio website was not changed by publishing this repository.

The existing cleaned Google Sheets copy still permits anyone with its link to view it; its sharing settings were left unchanged. Its current contents were reviewed, but Google ownership information and earlier workbook/script revisions were not erased or certified anonymous. Those limitations are documented in the [verification and privacy report](verification-and-privacy.md).

All financial figures in the public screenshots are fictional. They demonstrate the system and are not personal financial results, live market data or evidence of investment outperformance.
